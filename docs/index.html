Give your server a member that remembers

Olisar is a self-hosted AI Discord bot that knows your server, remembers context, is fully customizable, and feels like a part of your community.

Your bot

Customize everything

Give your Olisar a name, profile picture, and bio. You can also ask it to set its own status. A custom system prompt and style notes make Olisar talk the way you want in a unique persona.

Self-hosted shouldn’t mean overwhelming

All you need is to create a bot on the Discord Developer Portal, grab a Gemini API key, and the app does the rest.

It knows your server

Recent message context, rolling summaries, and a full server message index let Olisar always know what’s going on. Teach it documents or webpages like wikis for information it can pull any time.

Talks where you let it

Permissions for each channel

You choose which channels Olisar reads, talks, references, or ignores.

Not a chatbot

Olisar intelligently judges when it should speak up on its own. Hourly caps, quiet hours, and ping blocking give you control.

OpSec on

Olisar never shares with members private DMs or information which they shouldn’t see. PIN control requires an admin PIN to change certain settings.

Always on

On a server, 24/7

Set up a free Oracle Cloud VM or purchase cheap hosting from another provider to let Olisar stay on. A Linux machine with Docker works as well.

On this computer

Olisar can run entirely locally with almost no setup. It keeps running in the menu bar or system tray after you close the window.

On this computer, shared

Runs completely locally, but lets other admins access it via a free Tailscale link.

What Google sees

Its memory stays in one database on your computer or server. What it replies to goes through Gemini, and on the free tier Google may use that to improve its products. Turning on billing stops that, and the EEA, UK and Switzerland are exempt.

Maximize your free usage

When a model runs out of free requests for the day, Olisar falls back to the next best one, so the free tier goes further. The console shows what’s left of each model’s limit.

The Olisar console

Add extensions

Olisar extensions are toggleable packaged features that extend its functionality. Install them from the community marketplace or write your own with the TypeScript SDK.

Customize it all

Edit command replies, persona, and more. Members can see and change their privacy settings as well.

And everything else

Multi-bot switching, behavior tweaks, channel permissions, bot access, knowledge base and message index, member impressions, API keys, usage, and more.

Question and answer

Is it really free?

Olisar has no subscription. By default it runs on your Gemini key’s free tier, so the cost is a daily limit: once every model in its chain has hit its limit, it stops replying until midnight Pacific. Turning on billing for the key in Google AI Studio lifts the daily limit. Google then charges per use, and the console shows what it costs and can hold it to a monthly budget. Image generation is optional: it uses Gemini once billing is on, or a free Cloudflare key.

Does my computer have to stay on?

Only if that’s where Olisar runs. Closing the window keeps it running in the menu bar or system tray. To keep it online with your computer off, the app can set it up on a free Oracle Cloud server, or on any Linux machine with Docker.

Can one install run several servers, or several bots?

Both. A bot can join as many servers as you add it to, and you set it up for each one. The app can also run several bots at once, each with its own name, keys and data.

Does it run on Linux or an Intel Mac?

There’s no desktop app for either. On Linux you can run Olisar from source, and the desktop app can install it on a Linux server for you.

Can members see what it knows about them?

Yes. /privacy shows them what it keeps, /forget-me erases them, and the member portal lets them read and delete single facts. Members who opt out are never recorded.

Can I add my own commands?

Dice, a calculator and a concise mode come built in, and the console has a marketplace for more. You can write your own in TypeScript with the SDK; extensions run sandboxed.

Is the code public?

All of it, under the MIT license, on GitHub.
